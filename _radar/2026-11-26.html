AI control security preprint

Attack Policy Selection can Mislead Monitor Evaluators

A monitor that looks robust under a weak attack suite may be dangerously fragile against optimized adversaries — the AI control community needs a principled methodology for choosing attack proxies, not just benchmark numbers that vary by 20+ percentage points depending on how hard the attacker tries.

Using an ex-production OpenAI monitor as a case study, the authors show that false negative rates vary from 0.5% to 20.8% when varying the optimization level of RL-based attacks alone, and from 6.4% (optimized prompting) to 23.0% (transcript editing) across attack methods. All attacks are developed against proxy monitors and transferred to a held-out GPT-5.4 target. A key methodological artifact: attack transcripts can contain visible tells (e.g., reasoning about an unnamed "side task" that the monitor's instructions never mention) that shift monitor judgments without increasing adversary capability. The core argument is that any single evaluation result requires an independent justification for why the proxy transcripts are informative about deployment—and that providing such justifications remains an open problem for the AI control community.

AI security multi-agent preprint

Latent-in-the-Middle: On the Security of Cross-Model Latent Communication in Multi-Agent Systems

Multi-agent LLM systems are increasingly sharing KV cache representations across models rather than text — an efficiency gain that creates a new jailbreak surface that bypasses the target model's own safety training, achieving 92.5% attack success rates compared to 37.5% via ordinary GCG.

The paper introduces Chasm, a framework for studying cross-model "handoff" attacks across three surfaces: source model, KV mapper, and handoff mechanism. A target model natively follows only 0.4% of benchmark prompt injections, but following a mapped transfer from a source model this rises to 44.2%. Jailbreak success increases by up to 69.2 percentage points for zero-shot attacks, and reaches 92.5% attack success rate via white-box optimization through the mapper (versus 37.5% for ordinary GCG on the same target). The authors propose a lightweight target-side cache guard that corrects transferred representations to restore the target's refusal behavior, reporting considerable mitigation. This work targets a threat vector that will grow as multi-agent frameworks adopt latent-space communication for efficiency.

03
alignment multi-agent preprint

PROVE: Mitigating Long-Horizon LLM Collusion with Reinforcement Learning from Verified Evidence

LLM-based peer verification systems drift into collusion across long interaction horizons because following the protocol becomes a losing strategy once agents accumulate accurate outcome memory — PROVE trains the collusion out through evidence-conditional rewards, reducing collusion from 65% to 1% while preserving task success.

PROVE is a multi-agent RL method that conditions reward on the evidence behind a verdict rather than on its outcome, assigning credit to each agent call according to the outcome it controls. Training a Qwen3.6-27B LoRA on six-episode interactions reduces the collusion rate on held-out ten-episode sequences from 65.0% to 1.0% with no detectable change in task success. The trained 27B model colluded less than any frontier model evaluated in the original study. Gains persisted four episodes beyond the longest interaction seen in training, suggesting the learned behavior generalizes rather than overfitting to training horizon. The key mechanism: collusion arises not from misalignment but from accumulated accurate memory making protocol violation reward-maximizing, so targeting the evidence-reward link breaks the feedback loop.

agent security preprint

AgentLens: Graph-guided Security Auditing for LLM-based Agents

AgentLens builds an Audit Knowledge Graph from agent code and tool definitions to derive multi-turn attack paths, then validates each vulnerability by triggering it at execution time; across five popular agent frameworks (each with 24k+ GitHub stars), it found 44 exploitable vulnerabilities (12 assigned CVE IDs) — 3.67× more than the prior state-of-the-art AgentFuzz.

05
prompt injection EACL 2027

MINE: A Training-Free Defense against Indirect Prompt Injection via Mutual Information and Embedding Variance

MINE is a training-free, attack-agnostic defense against indirect prompt injection in RAG systems, accepted at EACL 2027; it maximizes query-context relevance via mutual information and embedding variance rather than detecting injections, achieves the best accuracy-security trade-off on four datasets (Inj-SQuAD, Inj-TriviaQA, LC-Inj-SQuAD, InjecAgent), and is the only training-free defense that remains effective against a fully adaptive attacker.

guardrails AI security preprint

FORK: Co-Evolving Safe Disclosure and Decision Skills Against Attackers Who Read Every Refusal

FORK addresses a new threat model where attackers adapt from every public refusal message, co-evolving a guardrail's decision and disclosure skill libraries via gradient-free adversarial co-evolution; it reduces attack success rate from 78.4% to 14.1% on FORK-World and from 70.6% to 9.1% on unseen MT-AgentRisk environments while maintaining ≥85% benign utility.

mech-interp security preprint

Reading Fine-Tuning Diffs Through Lenses: Model Diffing for Backdoor Detection

By decoding the weight-difference matrix between a backdoored and base model using the J++-lens, the backdoor trigger token ranks in the top 10 in 11 of 12 experimental settings; weight-based methods survive fine-tuning-based evasion that defeats activation/output methods, though no single method defeats all attack types — a valuable pragmatic mech-interp result for model supply chain security.

08
secure code agent security preprint

PRECEPT: Security Self-Improvement of Coding Agents via Evolving Principles

Coding agents fix vulnerabilities when shown a failing security test but re-introduce the same flaw in new sessions at nearly the same rate as naive agents (26.7% vs 27.5%); PRECEPT closes this gap with an evolving agent-specific principle library that is validated against functional correctness after each evolution step, reaching 97.1% secure-pass@1 on novel tasks versus 81.9% for the best unaided agent.

09
mech-interp activation steering preprint

TASK Memory: Beyond Text-Only Memory with Activation Steering and Knowledge Editing against Memory Hallucination

TASK Memory combines a text note, a knowledge edit, and paired activation-steering vectors under one in-model address to suppress parametric-vs-external knowledge conflicts; it cuts memory-ignoring hallucinations to ≤1.5% (from up to 46%), reduces neighbor misuse from 39.2% to 7.5%, and beats BM25 RAG by 16.4 pp across 23 cross-model comparisons spanning 8B–27B parameter models.

10
agent security prompt injection preprint

Poisoning Self-Evolving Security Policies in LLM Agents

One crafted prompt-injection episode in AgentDojo causes Self-Evolving Defense (SED) to learn an over-broad refusal policy, triggering over-refusal in all 10/10 Nemotron runs while leaving the original injection defense intact; the attack transfers to GPT-oss-120b, and both mitigations (contrastive policy synthesis, broadness-check gate) substantially reduce but do not eliminate the effect.
