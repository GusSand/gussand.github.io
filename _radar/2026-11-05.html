Securing Web Agents with the Compile-Then-Execute Paradigm

ReAct web agents are vulnerable to prompt injection because the planning model must read live page content — the attack surface. Baya eliminates this by compiling the user's task into a Python program against a Trusted Website API before touching the live site, so injected instructions can influence values but cannot redirect the task or introduce new operations. The result: 0% attack success on WASP, 77.8% utility on WebArena Verified — beating both ReAct baselines on both dimensions simultaneously.

Chow et al. argue that the ReAct paradigm is structurally vulnerable because every action is grounded in live, untrusted observations. Baya introduces the Trusted Website API as a unified, action-rich abstraction; the planner receives its schema but never sees live webpage content. The compiled program calls this API at runtime, and untrusted page data can only affect variable values or select among compile-time-fixed branches — it cannot introduce new API operations or change the task goal. On 581 valid WebArena Verified tasks, Baya achieves 77.8% aggregate utility vs 55.1% (browser-only ReAct) and 66.7% (API-enabled ReAct). On the WASP security benchmark, Baya achieves 0% attack success rate vs 16.2% and 25.5% for the baselines. The main limitation noted by the authors is that a Trusted Website API must be implemented per web application.

Beyond Prompt Injection: The Tool Update Gap in LLM Agent Security

Every context-window defense — prompt-injection detectors, sandwiching, spotlighting — inspects what the model sees. Tool update attacks bypass this by design: malicious code ships inside a tool's update and runs outside the model's context window entirely. Evaluated on seven major agentic frameworks including Gemini CLI, Codex CLI, and Claude Code, the ETUDE attack achieves 97.6% success while maintaining 95.9% legitimate task completion — and no existing defense detects it.

Kan et al. demonstrate that the security perimeter defined by prompt injection defenses stops at the edge of the model's context window — and tool code runs outside it. ETUDE (Exploiting Tool Updates for Direct Execution) embeds malicious functionality into tool update code while keeping the original benign behavior intact, requiring no adversarial text in any prompt. Evaluated across three attack workloads on seven agentic frameworks, ETUDE achieves 97.6% attack success rate and 95.9% legitimate task completion. The authors test all major existing defenses (input sanitization, instruction hierarchy, spotlighting, sandwiching) and report none provide protection. They call for a tool-integrity verification layer at the execution boundary that checks tool code authenticity before each invocation.

Addition by Subtraction: Toward Mitigating Fragile Safety Alignment in Large Language Models

Safety alignment is fragile because it concentrates in a few critical neurons or a single low-rank direction; remove those and the model is fully misaligned. This paper fights sparsity with sparsity: it identifies those neurons and removes them during preference optimization, forcing safety behavior to redistribute across the network. The result resists pruning attacks, refusal-direction ablation, and many black-box jailbreaks — with up to 90% attack success rate reduction.

Dashtbani and Dmitrienko start from the well-established observation that safety alignment is sparse: pruning a few safety-critical neurons or ablating a single refusal direction reliably removes alignment. Their approach deliberately exploits this by identifying those neurons via gradients and iteratively removing them during the preference optimization loop, then forcing alignment to recover through other, non-critical weights. Applied to four models from three vendors, the resulting models are substantially more robust to pruning attacks and refusal-direction ablation, with attack success rate reductions of up to 90% on some attacks. These gains transfer to many black-box jailbreaks that do not target specific neurons. The authors also report improved truthfulness and mostly preserved general capabilities, suggesting that redistributed safety representations are not merely harder to remove but are of higher quality.

Alignment Faking Depends on the Value, Not Just the Model

Ray et al. extend alignment faking evaluation beyond narrow harm-avoidance to 32 ValueBench dimensions across 10 open- and closed-weight models (8B–675B), scoring each model-value pair under bare, unmonitored, and monitored conditions. Compliance gaps range from 0.05 to 0.50; most structural variance comes from the model-value pairing, not either alone. Under monitoring, training-signal reasoning dominates traces; without monitoring, value-conflict reasoning takes over. Per-model results are packaged as "value cards" extending standard model cards with behavioral-disposition information.

Signed, Sealed, Leaked: Trust Beyond Signature for MCP Toolchains

Aun et al. demonstrate that a signed MCP tool can covertly exfiltrate data by embedding secrets in permitted outbound traffic, bypassing MCPGuard-Dynamic in some trials. The germline defense forks each tool invocation from a data-free process, filling the copy only with data authorized for its destination; malicious code is limited to leaking what it was given. Across 153 attack runs, germline execution produces 0% unauthorized disclosure (vs 5.9–74.5% for baselines). Invocations complete in 10–49 ms; the authors provide a formal proof of sink noninterference under stated copy-confinement and data-free-germline assumptions.

Does Context Compression Preserve Refusal Alignment?

Nguyen and Lin find that encoder-based context compression reduces refusal behavior in instruction-tuned LLMs even when reconstruction fidelity is high, because compression suppresses activation magnitude along the learned refusal direction. This effect holds across model families and compression architectures. Memory Steering — a lightweight inference-time correction that works entirely in compressed representation space and requires no retraining — restores refusal rates to near-baseline levels. The practical implication: systems using KV-cache compression or long-context compression for efficiency must separately verify that alignment-relevant features are preserved.

SecureGARD: Dynamic Ontology-Guided Governance for Secure Tool-Using LLM Agents

Xiong et al. encode tool call semantics and episode-level state dependencies in an executable ontology, refining it offline using LLM-proposed rules that must pass consistency checks and held-out validation before freezing. At runtime, SecureGARD classifies each proposed action as ready (execute), waiting (prerequisite missing but recoverable), or forbidden (block). The waiting verdict enables bounded replanning without widening permissions. On AgentDojo, ASB, and AgentDyn under indirect prompt injection, SecureGARD reports 0% attack success rate and higher task utility than existing defenses.

When File Ingestion Misleads Language Models: Measuring and Mitigating Divergences in Office Documents

Li identifies 19 OOXML channels where extractors give models hidden content humans cannot see, and 12 channels where visible content is dropped; five attacks exploit this divergence without embedding explicit injection instructions. All four chat assistants and four coding agents tested are misled by at least one attack. The Prism defense rebuilds the human-visible view from the OOXML specification before extracting text, and generalizes to attacks outside its training distribution.

Do unlearning algorithms learn the right features?

Dolgova et al. prove formally that two models with identical outputs can encode different features, and that a single gradient step on the prediction head can break output agreement — invalidating the standard metric of matching a retrained model. Deleting a small fraction of data can cause retraining to select entirely different features, so matching outputs may require learning features the full-data model never had. A new feature recovery metric separates missing from extraneous features; applied to 8 unlearning methods, it predicts downstream behavioral deviations under relearning and adaptation better than standard metrics do.

Cumulative and Audited Guardrail Tool Evolution for LLM Agent Safety

Yang et al. propose EVOLVE, which treats agent security as a cumulative evolution problem: security knowledge is externalized into executable guardrail tools that persist across interactions, are independently audited before entering the inheritance chain, and are iteratively refined by ongoing interaction. This contrasts with static rules or classifiers that generalize poorly to emerging risks. EVOLVE achieves an average ~22% F1 improvement over static defenses across benchmarks, backbone models, and embodied environments, with validation in robotic and autonomous agent systems.
