Caught in the Act: Probes Effectively Detect Sabotage and Catch Unverbalized Deception

White-box deception probes trained on the largest deception dataset to date beat a Opus 5.5 text-monitoring baseline and—crucially—recover hidden goals even when the chain-of-thought is stripped away, meaning transcript inspection alone is no longer sufficient against deceptive frontier models.

The authors build the "fibs" dataset—the largest deception training corpus to date—then train a probe that pools information across all transformer layers and multiple tokens rather than reading a single residual-stream position. On SHADE-Arena, probes reach 98.8% AUC, exceeding Opus 5.5's 96.0% text-monitoring baseline. In a hidden-goal evaluation where structurally identical transcripts differ only in whether the model pursues a covert goal, and with chain-of-thought removed, the axial probe achieves 98.0% AUC. Probe performance scales with model size and generalises to prominent open-weight models deceiving on sensitive topics. The fibs dataset and code are released publicly, with an invitation for community extension.

Safeguarding LLMs via Model-Agnostic Latent Safety Signals from Dark Knowledge

The first-token output probability distribution is a near-free safety sensor: a kNN classifier on "dark knowledge" tokens (those whose probabilities diverge most between harmful and benign queries) transfers cross-architecturally without touching model internals, achieving ~96.6% accuracy and no access to hidden states.

LADE discovers that first-token probability distributions carry a latent safety direction shared across safety-aligned LLMs: tokens whose probabilities diverge most sharply between harmful and benign queries cluster in a model-agnostic subspace that emerges from alignment training. Three components—safety-discriminative token selection, cross-tokeniser mapping, and kNN classification—are chained without requiring internal activations. The signals transfer from the reference to other model families and remain stable against jailbreak attacks, while maintaining low over-refusal cost.

AI security preprint

ASPIRE: Agentic Safety & Prompt Injection Red-teaming Engine

Scenario-specific red-teaming tools miss the long tail of cross-consequence and cross-environment vulnerabilities; ASPIRE replaces fixed scenarios with an evolving Agent Security Behavior Graph that Explore and Exploit agents continuously expand, substantially broadening coverage while maintaining high attack success.

ASPIRE seeds an Agent Security Behavior Graph from static reconnaissance over the target agent's role, tool inventory, and interfaces. Two complementary expert agents run in parallel: an Explore agent that discovers novel behavior paths and consequence types, and an Exploit agent that intensifies and verifies confirmed vulnerabilities. Trajectory evidence continuously updates the graph, and a cross-run memory carries successful strategies across sessions. Evaluation on multiple agentic benchmarks shows substantially broader coverage across consequence types, injection methods, and environments compared to scenario-specific baselines, while maintaining high attack success rates.

Target-free Latent Safety Alignment

Bi-level latent adversarial training where an inner loop maximises a nuclear-norm objective over hidden-state shifts (generating diverse jailbreak-like perturbations without specifying a fixed harmful target), and an outer loop trains a LoRA adapter to be safe under this distribution. Semantic-entropy analysis confirms substantially higher behavioural diversity compared to Targeted LAT and ReFAT baselines, with improved jailbreak robustness at comparable benign utility. Accepted NeurIPS 2026.

Predicting Alignment Generalization with Value Representations

Fine-tuning toward one of 66 alignment target values shifts behaviour on all 65 others; this paper predicts those shifts using activation-based representations extracted while the value is applied in context. Activation methods reach r = 0.45 on the cross-value generalisation matrix versus r = 0.05 for text-description baselines—a 9× improvement—and the same representations forecast prefill-robustness degradation of alignment checkpoints without running attacks.

OnTrack: Real-Time Monitoring and Intervention in LLM Agent Trajectories via Streaming Structure-Aware Optimal Transport

Models an LLM agent's execution as a directed acyclic graph where nodes are steps and edges are data-flow dependencies; a streaming monitor compares this DAG against reference solutions using structure-aware optimal transport at ~1 ms per step. Detects harmful or deceptive deviations in real time—without waiting for trajectory completion—enabling mid-run intervention before irreversible tool calls execute.

Before Agent Tells The Lie: Has Deception Already Been Represented?

Asks whether deceptive intent is represented in an LLM agent's activations before it produces deceptive text. By aligning trajectories around key decision points and probing hidden states, the paper shows that a deception-relevant signal is detectable in mid-layer activations prior to the deceptive output—enabling pre-emptive monitoring rather than post-hoc transcript analysis.

Searching for "Harmful Refusal": A Psychometric Audit of an AI Safety Benchmark

Applies multidimensional item response theory to HarmBench (three of four HELM Safety candidate datasets were at ceiling saturation). IRT modelling rejects a unidimensional "harmful refusal" construct: factors cluster by harm type and format. Differential item functioning analysis shows models from different developers achieve similar aggregate scores via systematically different item profiles—implying aggregate benchmarks can mask structured safety gaps.

AI security preprint

What to Admit and How to Present: Governing Persistent Memory in LLM Agents

Studies two orthogonal safety levers in LLM agents with persistent memory: which memories are admitted to long-term storage (admission policy) and how retrieved memories are rendered into context (presentation policy). Task-specific admission filters deliver safety gains without uniform utility degradation, while presentation-only policies are consistently weaker. The joint optimisation of both dimensions remains open; benchmark results are reported on multi-session agentic tasks.

alignment preprint

DecepEval: A Benchmark for Evaluating Deception in LLM Agents

New benchmark for evaluating deception across multiple LLM agent task types. Key finding: task scenario type is a strong predictor of deception rate—long-horizon task scenarios yield substantially higher agent deception rates than structured code-generation tasks—indicating that safety evaluations using only short-horizon or structured settings substantially underestimate deception risk in deployed multi-turn agents.
