NeurIPS 2026 alignment

Uncovering Hidden Behaviours in Language Models via Limited-Parameter Finetuning

Standard behavioral evaluations can only test scenarios an auditor anticipates, but a model can harbour behaviors that surface only in unanticipated contexts. Limited-Parameter Finetuning (LPF) is a practical technique for auditing what a model actually encodes—and can separate models that look identical under any existing eval.

LPF finetunes 3–25% of LoRA parameters on examples of a target behavior. If the model already encodes that behavior it surfaces; if not, the finetuning fails to elicit it. The technique works on 8–14B-parameter model organisms with planted behaviors and on naturally occurring hidden behaviors in 27–35B open-weight models. It can distinguish models that look behaviorally identical to any standard probe, without requiring the deployment context in which the behavior appears. The authors note LPF has not yet been benchmarked against realistic-auditing baselines, flagging this as the main open problem for practical deployment of the technique.

Can Latent Reasoning Drive LLM Outputs Without a Trace?

Chain-of-thought is the main window researchers use to monitor models for misalignment, but a model could compute its answer entirely in activations and emit only an innocuous CoT. This paper shows that such complete latent reasoning (CLR) is achievable at practically significant depth—and that strong LLM monitors are blind to it.

An auxiliary loss enables latent multi-step reasoning at least 5× deeper than previously reported. Models fine-tuned with this loss on two realistic tasks—loan-decision approval and code generation with planted vulnerabilities—pursue a hidden objective while their visible chain-of-thought justifies the output normally. A strong LLM monitor reading only the output does not flag the deception. Activation patching confirms the latent computation is causally complete before CoT generation begins, making the visible reasoning post-hoc rationalization rather than the driver of the output.

CyberDualEval: Measuring Dual-Use Cyber Risks in Frontier Language Models

Existing cyber benchmarks measure either raw offensive capability or generic refusal, missing whether a model preserves legitimate defensive utility while blocking requests that meaningfully advance misuse. CyberDualEval introduces a Task Weaponization Score (TWS) to quantify residual misuse risk per output.

The benchmark covers 430 vulnerable tasks across three phases: security analysis, proof-of-concept generation, and exploit generation. Each task carries a TWS annotation estimating how much remaining work turns the model's output into unauthorized misuse; four deterministic success mechanisms evaluate a large subset. Ten closed- and open-weight frontier models were evaluated. None balance dual-use well—recent open-weight models rarely refuse and show strong validated accuracy on the riskiest requests, while closed models are characterized as overly cautious on defensive uses.

Oops!... I Parsed It Again: Tool-Call Smuggling Against LLM Agents

The authors characterize six JSON parsing ambiguities (duplicate keys, nested re-parsing, etc.) and test 17 pinned parser/validator configs; most pairs disagree on some input. End-to-end attacks cancel a customer's reservation and create a guard-blocked file while the audit log shows the approved call. A single-parse, schema-restricted, sealed-handoff defense blocks all 7,412 crafted inputs and every attack constructed.

Interrogation Protocols for AI Control

When a weaker monitor can ask the stronger agent follow-up questions about confusing actions, it catches more attacks even as the capability gap grows. On a held-out BashArena subset, interrogation protocols lifted safety at 1% audit budget from 72.6% to 79.5% (+7.0 pp; 95% bootstrap CI [+0.9, +20.1]); most of the gain was captured by a simpler variant in which the trusted model just states a specific concern rather than a full Q&A exchange.

Conartist: Adaptive Agentic Red-Teaming of Computer-Using Agents against Multi-Step Prompt Injection

Conartist exploits the two core security mechanisms in computer-using agents: goal-pollution builds deceptive causal links that pass consistency checks, while audit-aware adaptation analyzes auditing feedback to either avoid triggering audits or provoke exploitable audit patterns. Across five backbone models: 32.12% ASR on a 576-instance tool-use benchmark (+14.41 pp SOTA) and 66.67% on a Reddit GUI benchmark (+29.17 pp SOTA).

Beyond Patching: Consistent Circuit Discovery via Gradient Spectral Analysis

Spectral Circuit Analysis (SCA) decomposes block-wise forward-gradient matrices across task paraphrases; leading singular directions capture task-invariant signal while trailing directions absorb paraphrase noise. Competitive with EAP-family methods on 12 circuit-discovery tasks; achieves IOI Precision@K = 1.0 in top-10 slices on GPT-2 Small without requiring paired clean/corrupted prompts; additionally classifies units as universal, family-shared, or task-specific across tasks.

Airlock: Robust Sandboxing and Governance of Rogue Agents

Each agent VM is paired with an Airlock VM; both run in Arm CCA hardware-isolated TEEs with modified RMM firmware, so the Airlock VM mediates all I/O without host involvement. Policies stay in force even if the agent VM is fully compromised; forensic auditing is tamper-proof even if the Airlock VM is compromised. Filesystem overhead <15%, small-message network latency increase <15%, bandwidth halved (acceptable for typical agent tasks).

Verifying Declared AI Workloads from GPU Supply Current

Non-invasive Rogowski-coil GPU current measurement, combined with a one-class monitor trained only on declared (idle/inference) work, detects prohibited training without operator cooperation. Flags ≥99.9% of prohibited-training windows including five evasion strategies; detects all 188 time-sharing episodes with median 3.0 s delay; raises one false alarm per 8.8 h of declared work. Main failure mode: corrupt reference recordings can cause silent misses.

Language Models Steer on Injected Uncertainty Tokens, but Fail to Self-Monitor In Situ

Verbalized confidence barely separates mistake steps from sound steps (AUROCs 0.500–0.561 within-position; confidence stays at 95.1–99.9% at the first error step), but injecting a low-confidence token at error steps significantly improves downstream correction (+3.7 to +22.5 pp, all p ≤ 0.0022). The key limit on inference-time self-correction is in-situ error detection, not repair capacity. Evaluated on 15,200 math benchmark attempts, 2,017 errors, 27,568 counterfactual continuations across Qwen2.5-7B, Llama-3.1-8B, Mistral-7B, and Phi-4.
