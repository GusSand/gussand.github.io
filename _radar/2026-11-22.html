alignment preprint

Sequential Anytime Valid Tests for Efficient Inference-Time Alignment

Best-of-N sampling is a workhorse for inference-time alignment, but every adaptive stopping rule so far has been a heuristic — it can certify the wrong answer with no known bound. This paper gives the first provably correct stopping rule: it draws candidates until a statistical test with error tolerance α certifies a dominant answer, and the probability of ever making a mistake is bounded by α, uniformly over time.

Candidates are scored with Reward-Weighted Self-Consistency (RWSC) and answer clusters are tested with an e-process (supermartingale betting) for each candidate answer. Unlike Wald's SPRT, the e-process guarantee holds even as the leading answer changes during sampling, bounding the probability of ever certifying a non-dominant answer by α uniformly over time. Required samples scale as O(log(1/α) / d_KL(θ* ‖ 1/2)), matching empirical observations across Qwen2.5-3B-Instruct and several other models on GSM8K, MATH500, MMLU, and CruxEval with ArmoRM as the reward model. Accuracy improves over fixed-N baselines while average token cost is substantially reduced.

AI security preprint

BlockJack: Cross-Tenant Redirection Fault Attacks on Paged KV Cache Address Translation in LLM Serving

vLLM's paged KV cache uses a block table to map each request's logical cache slots to physical memory — a structure analogous to OS page tables and, it turns out, equally exploitable. Flipping a single entry with a Rowhammer-style fault redirects one tenant's cache reads to another tenant's blocks, leaking private context or steering responses without touching model weights, prompts, or cached states.

The attack targets vLLM's block-table address translation: a request's logical KV slots map to physical blocks via a per-request table, and corrupting one entry with a Rowhammer fault (or equivalent physical bit-flip) redirects reads to another tenant's blocks. Tested across seven models from the Qwen, Llama, Gemma, and Phi families, corrupted mappings reliably exposed victim context. On a 248-scene medical benchmark, the integrity variant caused 41.1% of responses to recommend less urgent care while still appearing coherent with the victim's question. Physical feasibility was confirmed with Rowhammer on commodity DRAM; the authors propose block-assignment validation as a defense, and both vLLM and Sonar acknowledged the issue and proposed patches which the authors validated.

AI security mech-interp preprint

Jailbreak LLMs with Linguistic Style as a Hidden Attack Surface

The same harmful request, word-for-word identical in meaning but rewritten in different writing styles, produces attack success rates anywhere from under 6% to around 80% across state-of-the-art models. Style is not just an aesthetic property — it is a systematic, exploitable attack surface that current safety training largely ignores.

Across a taxonomy of linguistic styles, identical harmful goals rewritten in different styles produce ASRs from under 6% to ~80% on state-of-the-art models. The attack pairs a style-conditioned generator with a BERT-based style selector in a single pass, performing competitively with costlier multi-turn optimization attacks. Mechanistic analysis on LLaMA-3.1-8B shows that styled prompts reduce alignment with the refusal direction and suppress safety attention heads while keeping harmful intent recoverable via probing — suggesting distributed rather than localized refusal failure. A style-aware DPO defense reduces ASR from 86% to 19.5% while preserving most general capability.

DailySafe: Benchmarking Dynamic Safety Awareness in Everyday Multi-Turn Multimodal Interactions

Prior safety benchmarks test isolated harmful requests; DailySafe introduces 195 multi-turn, multi-image scenarios across 10 everyday domains and 42 task categories where risk is disclosed gradually, requiring models to track evolving context rather than detect a single unsafe prompt. Each case carries case-specific annotations for whether the model appropriately balanced safety and helpfulness.

mech-interp privacy preprint

Erasing the Wrong Thing: Conditional Attribute Leakage and Concept Erasure in Shared Foundation-Model Embeddings

A formal proof shows that global concept erasure (LEACE) cannot simultaneously remove a sensitive attribute and preserve task utility when the sensitive label and task label are correlated, leaving conditional leakage even when marginal audits pass. TC-LEACE fixes this by applying erasure within each task stratum; on 85 CelebA attribute pairs across four vision encoders and three biomedical models on chest radiographs, it recovers most utility while keeping conditional leakage within a specified margin.

SCARVA: Interpretable Agentic Reasoning in Software Supply-Chain Analysis

SCARVA makes LLM agent conclusions auditable for software supply-chain vulnerability analysis by recording every tool call, file access, and web request, then routing results to independent JUDGE agents. Qwen 3.8 as ANALYST achieves 82% balanced accuracy on 54 manually curated cases; Claude Opus 5.5 as JUDGE agrees with human annotators on 94% of individual claim checks. Interpretable, accountable agent reasoning for real-world security tooling.

mech-interp preprint

Probing the "Conscious" Mind: Selective Access and Global Workspace in Vision-Language Models

MC-Lens (Multimodal Concept Lens) uses a Jacobian-based projection to map both visual and linguistic VLM intermediate states into a shared output vocabulary space, finding that reliable selective concept access emerges later in training than basic accessibility, that accessed concepts demonstrably participate in downstream reasoning, and that J-space metrics track cross-modal alignment more cleanly than hidden-state cosine similarity. Results are consistent across VLM families and sizes.

Understanding MoE Decisions Beyond Gradients

In MoE models, swapping one expert can cascade through downstream routing decisions in ways that gradient-based attribution misses; this paper adds a correction term that models downstream expert-selection switches using the model's own expert outputs and routing rules, reducing attribution error by ~60% on Qwen3.6 and ~47% on Gemma4 on questions from three benchmarks, with practical relevance for auditing and debugging MoE model decisions.

Revealing Pathway Interactions in Network Computations with Complete Path Contribution

Path contributions from input to output are summed exactly at any circuit granularity (no residual), enabling completeness-preserving circuit analysis without approximation errors accumulating across levels. An efficient top-k path algorithm runs in roughly linear time in k rather than exponentially in depth; applied to image classifiers and an interpretable retina model to characterize excitatory-inhibitory pathway interactions.

mech-interp preprint

A CPU Inside an LLM: Zero-Gradient Compilation of Exact Circuits into Pretrained Weights

Deterministic arithmetic circuits (addition, subtraction, multiplication for 4–8 digit numbers) are written directly into pretrained LLM weights via a five-stage compiler using Mellin-GLU quadrature and cross-token scale cancellation, with no gradient training or runtime tool hooks. On 6-digit arithmetic, Qwen 3.5 4B reaches 100.00% and Granite 4.2 3B reaches 99.17% ALU-prefix accuracy, far ahead of LoRA baselines (61.7% and 42.2%), demonstrating that exact computational circuits can be mechanistically implanted into pretrained models.
